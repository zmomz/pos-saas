# ISSUE-054 — Coupons / trials

**Status:** ready-for-agent · **Type:** AFK · **Sprint:** 4 · **Findings:** P2 billing · **Stories:** 50

## Parent
[PRD — Platform Remediation](../prd/PRD-AUDIT-platform-remediation.md)

## What to build
Add subscription coupons (percentage/fixed, duration) and trial periods so new/existing subscriptions can start on a trial or apply a coupon at billing time.

## Acceptance criteria
- [ ] A coupon applies the correct discount for its duration to a subscription's invoices.
- [ ] A trial defers the first charge until trial end.
- [ ] Covered by tests for coupon application and trial-to-paid transition.

## Blocked by
- None - can start immediately
