## What to build
Enforce a configurable password-complexity policy (length, character classes) on signup, reset, and staff-login provisioning.

## Acceptance criteria
- [ ] Weak passwords are rejected with a clear message at all set-password entry points.
- [ ] Policy is configurable.
- [ ] Covered by a test for accept/reject cases.
