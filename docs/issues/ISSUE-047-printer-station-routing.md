# ISSUE-047 — Saved/selected printer + per-station routing

**Status:** ready-for-agent · **Type:** AFK · **Sprint:** 4 · **Findings:** H26/U5.2 · **Stories:** 47

## Parent
[PRD — Platform Remediation](../prd/PRD-AUDIT-platform-remediation.md)

## What to build
There is no saved/selected printer and no per-station routing. Let a merchant save a default printer and route printables (e.g. KOT to a prep-station printer, receipt to the front printer) per station.

## Acceptance criteria
- [ ] A merchant can save/select a default printer; selection persists.
- [ ] KOT/receipt route to the configured printer/station.
- [ ] Covered by a test of the routing resolution.

## Blocked by
- None - can start immediately
