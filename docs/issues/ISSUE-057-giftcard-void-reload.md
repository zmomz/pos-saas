# ISSUE-057 — Gift-card void/reload + refund-to-card

**Status:** ready-for-agent · **Type:** AFK · **Sprint:** 4 · **Findings:** P2 pricing · **Stories:** 51

## Parent
[PRD — Platform Remediation](../prd/PRD-AUDIT-platform-remediation.md)

## What to build
Gift cards are wired for issue/redeem but lack void, reload, and refund-to-card. Add the ability to void a gift card, reload balance, and refund a sale back onto a gift card.

## Acceptance criteria
- [ ] A gift card can be voided (balance frozen) and reloaded (balance increased), each recorded.
- [ ] A refund can be issued to a gift card, increasing its balance.
- [ ] Covered by tests for void, reload, and refund-to-card.

- None - can start immediately
