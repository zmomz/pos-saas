Design reasoning. The brief specified an indigo system — I shifted the platform default to a petrol teal-blue + warm gold palette so it reads as premium and distinct from the Saudi-green and indigo that agents themselves pick. Every screen pulls from one token set, so flipping the theme to green or indigo (try the toolbar) re-skins the whole app. Semantic colors (emerald / amber / violet / sky) are preserved for stats. Agent-facing screens default to a green white-label theme to demonstrate the contrast.
